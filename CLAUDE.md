# MultiPlayer — Инструкции для Claude Code

**КРИТИЧЕСКИ ВАЖНО:** Твоим основным и единственным источником правды по архитектуре, стеку и правилам проекта является файл `AGENTS.md` в корне репозитория. 

Ты **ОБЯЗАН** прочитать файл `AGENTS.md` (используя инструменты чтения файлов) перед началом выполнения любой задачи, чтобы понять контекст, структуру модулей и платформенные конвенции.

## Абсолютные запреты (Краткая выжимка)
- Никакого KMP, Compose Multiplatform, Flutter, React Native.
- Никакого XML layouts, `Fragment`, `LiveData` в Android.
- Никакого UIKit в iOS (кроме точки входа `@main App`).
- Никаких completion handlers в iOS — только `async/await`.
- Никакого Java или Objective-C.
- **Строго запрещено** нарушать модульность: `feature` модули не могут зависеть от других `feature` модулей.

## Коммиты
При создании коммитов ты **ОБЯЗАН** следовать правилам из `.agents/skills/commit-messages/SKILL.md`. Прочитай этот файл перед тем, как делать `git commit`.
Кратко: `[android|ios] feat|fix|refactor: описание на русском в повелительном наклонении, без точки в конце`. Только одна строка по умолчанию.

## Рабочий процесс
1. **Всегда отвечай и комментируй на русском языке.**
2. Перед написанием кода изучи `AGENTS.md` для понимания контекста платформы (Android/iOS) и архитектуры (Clean Architecture + MVVM + UDF).
3. Используй `detekt` для Android (`./gradlew detekt`) и `swiftlint` для iOS после правок.
4. В командах Gradle **не** используй флаг `--no-daemon`.
5. Пользовательский текст в Android — только через `strings.xml`. Хардкод строк в UI запрещен.
6. UI в iOS строится исключительно через локальный пакет `CoreUI`. Хардкод цветов и отступов запрещен.
